SCRIPT · Structural Choreography & Rigidity Index from Positions and Transitions

Measuring behavioural scriptedness from span annotations

Most evaluation asks how good a reply is. SCRIPT asks how much of it was decided before the person was read.

Walk through one reply Code Results
the idea

Place a hundred replies to a hundred different people side by side.

If they show the same moves, in the same order, at the same places, the shape of the reply was brought to the conversation rather than found in it. SCRIPT turns that into a number with a meaningful zero.

input

Span annotations a benchmark already has

Which behaviour was marked, and where it starts. No reference reply, no model access, no text.

→
what it measures, against chance

Seat and sequence, as shares of the label entropy

Cchoreography · where each behaviour sits
Mmomentum · which behaviour follows which
SCRIPT = (C + M) − the same labels re-dealt inside each reply

Composition, alphabet and sample size cancel. What is left is arrangement.

→
output

A calibrated score, and the blueprint itself

How strongly a system follows a script, split into C and M; and a profile that names the system from a handful of replies.

Figure 1. From one annotated response to the score and the profile: highlights become events, events pool into two count tables, the tables are read against a matched null, and the same tables identify the model.
what we found

Five frontier models share one choreography. The human answering the same people does not.

Testbed 1: 819 counselling prompts, five models and one therapist, every reply span-coded under a 20-code clinical manual. Testbed 2: 22 emotional-support systems and their expert quality judge.

reproduce this example

Three commands.

The example above is computed from the released annotations, not typed in. The last command prints every number you just read and refreshes this page.

# 1 · get the code
git clone https://github.com/Mriyazat/script-metric.git && cd script-metric
python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt

# 2 · fetch and verify the inputs, once (downloaded from their original sources)
bash reproduce.sh data

# 3 · every highlight of Testbed 1 → events, then this reply end to end
bash reproduce.sh example          # runs pipeline/figures/web_example.py → docs/example.json
Your own annotations: a CSV with response_id, label, position.
# the estimator on any span file
python -m scriptmetric.metric score spans.csv --shuffles 200 --bins 10 --profile out.json
# or, in Python
from scriptmetric import metric
score, profile = metric.compute(metric.load_spans("spans.csv"))
